# Dark Triad Flow

Dark Triad Flow is a lightweight browser app built around three connected tools:

- calendar scheduling
- task prioritization
- date-based notes

The interface is split into separate pages:

- `index.html` for the home overview
- `calendar.html` for the calendar and day schedule
- `tasks.html` for capture, ranking, and the task board
- `notes.html` for date-based notes

## Run it

Open `index.html` in a browser, or serve the folder with a simple static server and open the page you want.

## What it does

- plans the current week in a 7-day calendar view
- assigns tasks to real dates instead of leaving them floating
- ranks best next moves using time, energy, due dates, and mode
- stores a note for each selected day and autosaves it
- keeps everything in `localStorage`
